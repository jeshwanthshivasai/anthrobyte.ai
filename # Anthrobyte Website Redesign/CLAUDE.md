# Project brief (persistent)

Unsolicited redesign of https://anthrobyte.ai — enterprise AI company (supply-chain AI agents, "AATLAS"). Current site is a generic Next.js template; goal is an awwwards-level, premium, scroll-driven experience.

## Deliverables
- 4 pages, EACH its own standalone HTML file: Home, AAtlas Agents, AI Transformation, Journal.
- Each page must be a scroll-driven experience with WebGL elements + simple 2D isometric SVG elements, animated.
- User will port them into Vite/Next in their IDE later → keep dependencies CDN-light (three.js ok), code portable, vanilla scroll engine.

## Inspirations given by user
vecton.ai (read: dark, single red accent, isometric 3D cube motif system, by Everything Design), sisa.ai, ayr.energy, fortunaidentity.com, indigoedge.com, kandou.ai, wowfactories.com (still to read).

## Key research artifact
`Anthrobyte Audit.dc.html` — full teardown of the live site: page-by-page section maps, tech findings, verbatim content bank (agents + metrics, frameworks, copy lines), diagnosis, 3 direction seeds, open questions.

## Status
Dossier delivered; awaiting user brainstorm → then lock direction, build Home first.
