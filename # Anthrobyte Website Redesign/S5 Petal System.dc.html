SECTION 5 · ONE PRIMITIVE, FIVE AGENTS
Every agent is the same three petals, rearranged.

Nothing here is imported artwork. There is one petal path — the mark's — instanced eighteen times. Each agent is a different arrangement of it, and switching agents moves the petals rather than swapping a picture. That is what makes the five read as one continuous object.

ARRANGEMENT · NETWORK
Eighteen petals, six triads. Hidden triads scale to nothing rather than being removed, so the count never changes and every switch is pure movement. The dashed links are generated from the triad positions, so the scaffold can never disagree with the arrangement.
